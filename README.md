# AdventOfCode2025

Advent of Code 2025 — Solutions

What is Advent of Code?

Advent of Code is an annual series of programming puzzles that run each December. Each day (1–12) provides a puzzle with two parts. Solving Part 1 typically precedes Part 2, and both parts use the same input for that day.

Repository layout

- Each day has its own project directory: `Day1`, `Day2`, ..., `Day25` (as added).
- Inside a day folder you will find the solution source (for example `Program.cs`) and input files for that day's puzzle.

Notes about parts in this repository

- Each puzzle has two parts. Historically I implemented Part 1 first and then modified the code for Part 2.
- For Days 1 through 5 the repository currently contains only the Part 2 solution — I modified the Part 1 solution in-place and did not keep the original Part 1 method separate.
- Starting with Day 6, the original Part 1 solution is preserved in a `Part1` method inside the day's code; the Part 2 solution is implemented separately. Check `Program.cs` in each day's folder for the exact structure.

Notes

- Projects target .NET 9.
- See each day's folder for specific input filenames and implementation details.
